GestureMouse STM32 es un proyecto de sistema embebido portátil tipo guante, diseñado para detectar movimientos de la mano y un dedo mediante sensores IMU. El sistema usa un microcontrolador STM32F030 para leer los sensores por SPI y procesar la información como base para generar acciones tipo mouse. La primera etapa del proyecto se enfoca en validar la PCB, la alimentación, la programación por SWD y la comunicación con las IMU.
