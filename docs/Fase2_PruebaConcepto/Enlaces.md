# Enlaces de la Prueba de Concepto

En esta sección se incluyen enlaces externos y repositorios relacionados con el desarrollo de la Prueba de Concepto del GestureMouse STM32.


## Datasheet STEVAL-STLKT01V1 SensorTile Kit:
Documento de referencia sobre la plataforma SensorTile de STMicroelectronics, usado como base para comprender la integración de sensores de movimiento, microcontrolador y comunicación inalámbrica en un sistema embebido compacto.

https://www.st.com/resource/en/user_manual/um2101-getting-started-with-the-stevalstlkt01v1-sensortile-integrated-development-platform-stmicroelectronics.pdf

## Repositorio Del Ejemplo:
Repositorio usado como referencia para la prueba de concepto con SensorTile y el firmware FP-SNS-ALLMEMS1.

[Mariana-zy/fp-sns-allmems1](https://github.com/Mariana-zy/fp-sns-allmems1)

## Video de la prueba de concepto:
Video donde se muestra la validación inicial del proyecto usando el kit SensorTile y la visualización de datos de sensores.
